# 🔴 ABOUT THIS PROJECT

A fully integrated end-to-end Book Sales Analytics ecosystem designed to simulate enterprise-grade data architecture and executive decision systems.

This solution demonstrates ownership of the entire analytics lifecycle:

• AI-assisted dataset preparation  
• SQL transformation & structured engineering  
• Python analytical modeling (NumPy, Pandas)  
• Visual storytelling with Matplotlib  
• MongoDB data storage architecture  
• Power BI executive-level dashboard delivery  
• Excel-based validation & preprocessing
